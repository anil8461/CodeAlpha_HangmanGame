# 🎮 Hangman Game

A simple **text-based Hangman Game** developed using Python as part of the **CodeAlpha Internship – Task 1**.

The player has to guess a randomly selected word one letter at a time. The player is allowed a maximum of **6 incorrect guesses**.

## 📌 Features

* 🎲 Random word selection
* 📝 5 predefined words
* 🔤 Letter-by-letter guessing
* ❌ Maximum 6 incorrect guesses
* 🔄 Repeated letter validation
* ✅ Win and Game Over conditions
* 💻 Simple console-based interface

## 🛠️ Technologies Used

* `random`

## 🎯 How to Play

1. Run the Python program.
2. A random word will be selected.
3. The hidden word will be displayed using `_`.
4. Enter one letter at a time.
5. Correct letters will be revealed.
6. You can make up to **6 wrong guesses**.
7. Guess the complete word to win.
8. If you reach 6 wrong guesses, the game ends.
